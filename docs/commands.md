# 指令与帮助

每项功能只提供一个明确名称。指令后的参数用空格分隔，例如“面板 艾莲”。插件前缀和独立调用别名仍由命名空间配置决定；下文不指定固定前缀，使用时请加上目标插件的当前调用标记。

## 怎样查帮助

所有插件及系统管理统一采用：

- `帮助`：常用操作与一句话用途。
- `帮助 <指令名称>`：用途、参数、示例、作用范围及必要限制。也可传入当前命名空间下的完整指令。
- `帮助 全部 [页码]`：完整指令清单，每页最多14条。

例如在 ZZZ 插件中查询 `帮助 绑定设备`；在 ChatAI 中查询 `帮助 模型切换`。帮助只读取指令信息，不执行查询对象。系统管理与 ChatAI 的帮助仍执行各自管理员权限检查。

## ZZZ：认证、设备和游戏角色

| 指令 | 用途 |
| --- | --- |
| `绑定 [Cookie]` | 绑定米哈游认证；无参数扫码，有 Cookie 则导入 |
| `扫码登录 [web] [重建设备]` | 显式发起扫码认证；正常重新扫码保留已有设备 |
| `取消扫码` | 取消当前扫码会话 |
| `绑定国际服 <Cookie>` | 导入国际服 Cookie 认证；不提供国际服扫码 |
| `绑定设备 <设备JSON>` | 为已有账号绑定常用设备信息；不带参数查看脱敏状态 |
| `删除设备` | 清除设备信息，保留账号认证 |
| `默认设备` | 补全缺失设备标识和官方指纹 |
| `更新设备指纹` | 沿用设备 ID 和设备档案，重新申请官方指纹 |
| `解绑` | 解除当前用户与当前米哈游账号的绑定 |
| `角色列表` / `切换角色 <UID>` | 查看或选择已绑定的游戏角色 |

Cookie、设备写入、扫码和解绑仅在私聊操作。设备信息辅助通过社区设备校验，不保证解除所有风控；它不能代替账号认证。共享同一社区账号的绑定也共享设备配置。

`当前卡池` 查询官方当前安排；`卡池历史` 查询公开历史；`复刻统计` 统计已收录角色卡池的出现次数。它们是三个独立功能。`更新卡池` 刷新公开历史来源。

## ChatAI：一条模型配置路径

1. `连接新增`：填写服务地址与密钥环境变量名。
2. `发现模型 [连接名称或ID]` 后回复编号，或使用 `模型新增 [连接名称或ID]` 手动填写上游模型 ID。
3. 填写显示名称，回复“确认”保存，或“确认并使用”同时应用于当前会话。

仅有一个连接时可省略连接参数。旧的四步模型新增向导已移除；已有连接、模型及其稳定 ID 不变。

| 容易混淆的指令 | 区别 |
| --- | --- |
| `连接修改` / `模型修改` | 前者修改服务地址和密钥引用，影响该连接下全部模型；后者只修改一个模型的上游模型 ID |
| `设置` / `状态` | 前者显示当前配置与操作入口；后者显示运行情况、额度和最近生成结果 |
| `模型切换` / `默认模型` | 前者只影响当前会话；后者设置跟随默认的会话使用的全局模型 |
| `人物导入` / `人物编辑` / `人物覆盖` | 新增人物卡 / 修改单个字段 / 整卡替换并保留绑定 |
| `上下文` / `记忆列表` / `生成摘要` | 当前人物分支的对话状态 / 本会话显式长期记忆 / 调用模型保存对话摘要 |
| `清空上下文` / `删除摘要` | 清除当前分支对话及摘要 / 只删除摘要；两者都不删除显式长期记忆 |

模型显示名称通过 `模型命名` 修改；温度、输出、超时和上下文预算通过 `模型参数` 修改。模型检测检查密钥配置与模型列表接口，不发送聊天生成请求。

ChatAI的`设置`同时提供全局默认和本群/本会话覆盖，例如`设置 全局 人物 <人物ID>`、`设置 本群 插话 冷却 120`。局部填写`跟随全局`可移除该字段覆盖，默认值不会被复制到每个群；配置保存到数据库并实时读取。模型选择仍使用`默认模型`/`模型切换`。人物列表中的选择编号仅供本次私聊列表选择，明确标注的ID才用于人物参数。完整参数见[chatAi使用说明](chat-ai.md#全局默认与会话覆盖)。

## 旧指令迁移

兼容叫法已经移除，不再作为隐藏入口保留。常见替换如下：

| 原叫法 | 当前名称 |
| --- | --- |
| 扫码、扫码绑定、二维码登录等 | 扫码登录 |
| 扫码终止 | 取消扫码 |
| 选角色、设置角色 | 切换角色 |
| 体力、电量 | 便签 |
| 深渊、防卫战、剧变节点 | 式舆防卫战 |
| 危局、拟境、爬塔 | 危局强袭战、全息拟境、模拟鏖战试炼 |
| 资料、名片 | 绳网资料 |
| 排名 | 群排名 |
| 角色名＋面板、刷新面板 | 面板 角色名、更新面板 |
| ChatAI 的“说” | 对话 |
| ChatAI 的“连接模型新增” | 模型新增 |
| 菜单、help | 帮助 |
| 系统 auth、绑定管理、登录管理 | 认证 |

系统管理其余指令统一保留中文首选名称。此前捆绑的 `/便签`、全角斜杠和不带命名空间等11个快捷入口已从默认配置移除，请使用目标插件当前前缀。总线仍支持维护者显式配置快捷入口；升级已有自定义部署时，检查实际装载的 `shortcuts` 配置。
