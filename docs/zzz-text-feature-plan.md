# 绝区零纯文本功能补齐方案

## 当前决策

用户要求补齐功能、使用纯文本数据流降低开销，并将仓库定位为可通过配置扩展不同游戏、社区与业务的插件平台。`../zzz-bot` 为用户自有项目，其面板等定制行为是内部需求依据，不是外部致谢对象；新版不依赖旧宿主和旧数据。外部源码仅复制许可明确、宽松兼容的代码，AGPL 只参考功能。

此文件记录已确认的范围及验收约束，不代表所有功能已经线上验收。用户随后明确批准“迁移明确了，功能差异按照上一次的结论实行”，架构迁移和纯文本功能已进入实现；当前工作区还包含其他工具的后续修复。线上问题与本轮验证见 [回归修复记录](workflows/2026-10-25-live-regressions.md)。

| 自定义功能来源未完整核对 | 用户自有 `../zzz-bot` 仅用于对齐面板等具体优化，不列入外部致谢 |

不开发 AI 搜索、上下文记忆、模型接口切换或自主运维；只预留显式命令、业务文本、兜底的通用路由契约。

## 优先的架构增量

1. 包分类为 `packages/core`、`packages/channel/<id>`、`packages/provider/<id>`、`packages/plugin/<id>`。具体实现各有 package.json；同步 workspace、依赖、入口、测试及容器构建，不只移动目录。
2. 注册以稳定 moduleId / pluginId 为主键；gameId 是可选业务元数据，provider 依赖按能力声明为零个或多个。core 不写死 ZZZ 默认配置，也不向所有插件预先注入游戏角色。
3. 配置装配代替 app.mjs 中逐个模块的固定 import／注册；新增合规模块仅增加包和配置。发现不等于启用，不执行未启用模块的初始化。
4. 提供统一命令格式化服务，按目标 routeId 和当前上下文读取最新配置。帮助、错误、参数说明、长流程结果与任务通知都使用它。
5. 定义 NOT_MATCHED / HANDLED / FAILED / DENIED，以及显式命令 → 业务文本 → 已启用兜底的阶段；chatAi 以后按同一契约加入。
6. 移除业务图片路由、说明与实现；保留扫码认证所需的二维码。根 README 说明平台契约，进展与功能矩阵放插件文档／过程记录。

架构验收必须包含：新增无 gameId、无米游社依赖的测试插件；通过配置启停及装配；多 provider 能力绑定；实时更改命名空间后的全部提示；命令失败和未知命令不进入兜底；图片路由移除而扫码回归保留。

## 实施与数据边界

- 顺序：先完成上述平台契约和包组织迁移，再 provider 与身份／存储基础，再资料／战绩、面板与命令自动更新抽卡，再月报／公共内容，最后调度与排名；每个实际完成项同步状态。
- 复用当前网关、dispatcher、Vault 和扫码回归；允许按明确契约扩展内部接口。MIT SDK 只裁取确有价值且已核实的部分，不引入完整生成客户端的重依赖。
- 新表使用独立命名与可重入初始化；不自动导入旧库，不猜测账号归属。既有绑定和扫码流程必须保留回归。
- 凭据、authkey、ticket 和密钥不进入普通日志、群回复、榜单或导出；公开查询不借用其它人的私有凭据。
- 公开 UID 与凭据账号分开建模：公开展柜只能查询公开数据，不能据 UID 获得账号绑定或私有接口权限。
- 数据存储记录用户／账号／游戏／区服／周期／来源等适用维度。主角色选择按用户和游戏隔离。
- 任务实际执行和主动发送需有显式用户配置；开发只调用注入的假外部服务。没有其它启动、部署或付费调用授权。
- 核对每个接口和算法的真实字段、输入范围和适用版本后再实现；未说明的未来产品选择不从旧代码或设计报告中推导。
- 攻略来源若仅提供图片，本轮只提供真实来源链接并说明内容形式，不为节省开销而引入 OCR／视觉模型，也不编造文字摘要。

## 评分和伤害的验收约束

纯文本不减少计算本身的工作。必须列出上游锁定版本适用的规则与角色，并为独立实现建立覆盖矩阵和基准数据。不能只做一个通用攻击乘系数公式就宣称完成全部角色专属伤害，也不能把规则未覆盖隐藏成成功结果。范围内仍有缺项时保留未完成状态并记录原因。

## 风险与恢复

风险等级为 HIGH：涉及凭据、权限、持久化、跨模块契约及自动外部操作能力。代码实施已获用户明确授权；部署、生产数据操作及真实签到／推送未授权。

新模块默认不产生外部副作用；数据变更先用临时库验证。回滚按本轮补丁和可兼容的表扩展处理，保留本轮前的未提交修改。不替换运行中的服务，不写生产库，不创建后台进程。

自动化验证覆盖静态、运行逻辑、集成和数据库。真实 QQ／米游社／Enka 验收与账号授权需要另行安排；mock 通过不替代在线验证。图片和视觉验收本轮不适用，扫码流程既有的人机授权边界保留。
